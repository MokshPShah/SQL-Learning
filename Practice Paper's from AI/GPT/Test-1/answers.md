Section A – Subjective Questions (10 Marks)



**1. Explain SELECT statement with example. (2 Marks)**

A. **SELECT** statement in SQL is used for selecting the data from the table 

&#x09;eg. **SELECT \* FROM PracticeHubDB;**

&#x09;This will select all the data from the table **PracticeHubDB**.



**2. What is the use of WHERE clause? (2 Marks)**

A. The **Where Clause** is used when we want data based on the condition then we use this clause.



**3. Explain DISTINCT keyword with example. (3 Marks)**

A. The **DISTINCT** keyword is used when we want to get the unique values from the dataset.

&#x09;eg. SELECT DISTINCT col\_name FROM table\_name;



**4. Write difference between DELETE and TRUNCATE. (3 Marks)**

A. **DELETE** command is used to delete the whole table and **TRUNCATE** command will delete the data only not whole table.
